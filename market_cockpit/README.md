# 市场风险驾驶舱 · Market Risk Cockpit

用本地 moomoo/Futu OpenD 的真实数据，生成一个 5 级市场预期 + 独立风险等级的单文件仪表盘。
界面**中英双语可切换，默认英文**（右上 `EN / 中`），选择记在 localStorage。

## 跑起来

前置：moomoo OpenD 在 `127.0.0.1:11111` 运行并已登录。

```bash
cd "/Users/antaiwei/Claude Code/market_cockpit" && python3 build_cockpit.py
```

产物 `market_cockpit.html`，双击即可在浏览器打开。

其他用法：

```bash
python3 build_cockpit.py --date 2026-07-29   # 指定快照日
python3 build_cockpit.py --dry-run           # 只打印评分与 JSON，不写文件
```

## 评分模型

```
综合分 S = 0.30·Fed + 0.30·财报 + 0.20·新闻 + 0.20·技术面      （各因子 −100…+100）

S ≤ −60  → 1 极度看空        +20…+60 → 4 谨慎看多
−60…−20 → 2 谨慎看空        S ≥ +60  → 5 强烈看多
−20…+20 → 3 中性
```

风险等级与方向**独立**：`风险分 = 波动率×0.6 + 事件密集度×0.4`，映射 1–5 级。
看多不等于低风险 —— 「看多 + 高风险」= 可参与但控仓。

## 数据来自哪里

**自动（3/4 因子，实时拉取）**

| 因子 | 接口 | 算法 |
|---|---|---|
| Top100 财报 | `get_earnings_calendar` | `√市值` 加权 EPS 超预期幅度，截断 ±25% |
| 技术面情绪 | `subscribe` + `get_cur_kline` (SPY) | 相对 MA50 / 相对 MA200 / 20 日动量，等权 |
| 宏观意外 / 通胀追踪 | `get_economic_calendar`（3天分片+递归二分） | `actual` vs `consensus`，通胀与失业率反向计分 |
| 重大新闻 | `get_search_news` | 关键词词干 + 否定/紧缩预期规则；逐条给出**利好利空程度 1–5** 与**风险 1–5 星** |
| 顶部行情条 | `get_market_snapshot` | SPY / QQQ / USO / BNO / TLT / GLD 最新价与涨跌幅 |
| 美债收益率曲线 | `get_economic_calendar` | 12 个期限的**国债招标中标收益率**（各期限招标日不同） |
| 恐慌贪婪代理 | `get_cur_kline` (SPY/TLT/HYG/LQD) | 5 分项均值：动量、52周价格强度、波动率、避险需求、信用偏好 |

**人工（必须手工维护，在 `build_cockpit.py` 的 `MANUAL` 字典里）**

| 字段 | 为什么不能自动 |
|---|---|
| `fed_policy_stance` | 点阵图、票委表态、市场隐含路径 OpenD 都没有 |
| `fed_rate_low/high`、`next_fomc` | 同上，需从 federalreserve.gov 维护 |
| `cnn_fear_greed` | CNN 官方指数含期权比率与广度分项，OpenD 无法取得，只能人工填为对照；页面主指标是自建代理 |
| `brent_spot` / `wti_spot` | Futu 无原油期货/现货，只有 USO/BNO 这类 ETF（跟踪期货、有滚动损耗），**不等于油价**；ETF 涨跌幅是自动的，真实报价须手工填 |
| `vix` | Futu 取不到 VIX 指数（`US.VIX` 报 Unknown stock），只有 VIXY 期货 ETF。留 `None` 会自动降级为 SPY 21 日已实现波动率，页面会标注「代理值」 |

改 `MANUAL` 时**同步更新 `fed_stance_reason` 和 `fed_source`** —— 这两个字段会直接显示在页面上。
页面上每个因子都带 `自动` / `人工` 标记，没有出处的数字不应该出现在这个页面上。

## 实测踩到的坑（已在代码里处理）

1. **日历接口单次跨度上限 7 天** —— 超了报 `Date range must not exceed 7 days`。`date_chunks()` 负责分片后合并。
2. **返回值元组长度不一致** —— `get_economic_calendar` 返回 4 元组、`request_history_kline` 3 元组、`get_search_news` 2 元组。统一用 `res[0]` / `res[1]` 取，不要解包成两个变量。
3. **经济日历的 `next_page` 游标不可用，别翻页** —— 游标是**时间戳**，同一时刻的多条事件跨页时会被整组跳过。实测分片 `7/28~8/03` 共 89 条，page1 满 50 条后 token=`1785414600000`（正是 7/30 05:30），page2 从该时刻**之后**续取，把同一时刻剩下的事件全丢了：`Core PCE Price Index (YoY)` 与 `Core PCE Prices` 消失，而同批发布的 `(MoM)` 却在 —— 表面看数据正常，极难察觉。正确做法是**递归二分**：窗口报 `has_next` 就把日期范围拆半重取，永远只用每个窗口的第一页（`fetch_econ_window()`）。
4. **经济日历会给未来事件预填 `actual`** —— 实测 145 个事件里 46 个如此（8/6 的初请失业金在 8/2 就写着 199）。**不能凭 `actual` 是否存在判断有没有发布**，必须严格按时间戳与真实当前时刻比较，否则占位值会污染宏观意外评分。
5. **经济日历限流 60 次/30 秒** —— 递归二分会明显抬高请求数，实测 7 天分片直接打满并丢掉最后 12 天日历。对策：econ 改用 **3 天分片**（通常单页装得下，极少触发二分）+ 滑动窗口限流器 `_econ_throttle()`（仅在逼近上限时才 sleep）+ 对 `high frequency` 错误重试一次。修好后一次完整构建约 6 秒。
6. **历史 K 线有配额**（实测 100 次/30 天）—— 反复重建极易打满并报 `Insufficient historical K-line quota`（要等 7 天释放）。改用**订阅式 `subscribe` + `get_cur_kline`**，不消耗该配额，一次能取 300 根日线；同时本地缓存到 `.cache/`，历史接口只作兜底。
7. **新闻必须指定 `news_sub_type=NewsSubType.NEWS`** —— 默认 `ALL` 会混入 `NOTICE`（交易所公告）。搜 "Federal Reserve" 会命中 A 股**联储证券**（Federal Reserve Securities）几个月前的公告。
8. **新闻 `publish_time` 没有年份**（只有 `M/D` 或 `HH:MM`）—— `parse_news_time()` 以 as_of 反推年份，再按 `news_max_age_days` 过滤陈旧命中。
9. **情绪词表的否定陷阱** —— "Hopes for a rate cut **dashed**" 含 "rate cut" 会被判利多。用 `OVERRIDE_RULES` 优先拦截否定式；而 "维持利率" 这类规则必须放 `FALLBACK_RULES`（兜底），否则会盖掉 "Lose Steam" 这种明确利空。
10. **VIX 指数取不到** —— 见上表。
11. **EPS 口径混杂** —— 实测 SK hynix 预期 4.87 / 实际 90.36（韩元 vs 美元）、Alphabet 2.90 / 9.11。`classify_surprise()` 只把**同号且量级差 5 倍以上**判为口径问题并剔除；符号翻转（如 Intel 0.08 → −2.16）是真实业绩，保留并按 ±25% 截断 —— 若按百分比一刀切剔除，会把真实利空抹掉，因子系统性偏多。
12. **EPS 四舍五入** —— Tesla 实际 0.3200 / 预期 0.3203，显示都是 0.32 却被判「不及」。±0.5% 容差内记为「符合预期」。
13. **代码符号会撞上真实股票** —— 想取原油时别猜代码：`US.CL` 是**高露洁**(Colgate-Palmolive)、`US.WTI` 是 **W&T Offshore**、`US.BZ` 是 **BOSS 直聘**。这些都会正常返回快照，不报错，直接拿来当油价就完全错了。Futu 只有 `US.USO`/`US.BNO` 这类原油 ETF。同理收益率指数 `US.TNX`/`US.TYX`/`US.IRX` 全报 Unknown stock。
14. **美债收益率只能从招标结果拿** —— 无收益率指数，改从经济日历取 `N-Year Note/Bond Auction`、`N-Week/Month Bill Auction` 的中标收益率（`treasury_curve()`）。实测 10 年期招标 4.683（8/12）与公开的 10Y 4.69%（8/17）几乎一致，来源可靠。**但各期限招标日不同**，页面必须逐个标出日期，否则会被误读成同一天的曲线快照。
15. **因子不可用 ≠ 中性** —— 取数失败时因子返回 `None` 而非 0，上游剔除该因子并**重新归一化**其余权重，页面显示 `n/a` 与「权重已重新归一化」。返回 0 会让「没有数据」伪装成「市场中性」。

## 恐慌贪婪指数（自建代理，非 CNN 官方）

CNN 官方用 7 个分项，其中**看跌看涨期权比率**与 **McClellan 广度指标** OpenD 拿不到。
本页用 5 个可自动取数的分项自建代理，每项归一到 0–100（50 中性）后取平均：

| 分项 | 算法 | 归一区间 |
|---|---|---|
| 市场动量 | SPY 相对 MA125 偏离 | ±14% |
| 价格强度 | 现价在 52 周区间中的位置 | 天然 0–100 |
| 波动率 | 21日已实现波动率 ÷ 100日 | 比值 1.6→0，0.6→100 |
| 避险需求 | 20日 SPY 收益 − TLT 收益 | ±12% |
| 信用偏好 | 20日 HYG 收益 − LQD 收益 | ±4% |

**归一区间不能设窄。** 动量最初用 ±8%，结果 SPY 高于 MA125 仅 8% 时读数就到 99.9，
任何一轮正常上涨都会饱和 —— 与事件密集度硬截断是同一类错误。放宽到 ±14% 后恢复分辨率。

代理值与 CNN 官方存在十几分的差距是**正常且预期的**（分项不同、归一方式不同）。
不要为了对上官方数字继续调参，那是在制造虚假一致。CNN 数字仅作对照显示在页面右上。

## 新闻的两个评级维度

每条新闻给两个独立评级，页面上有图例说明：

- **利好利空程度 1–5**（颜色渐变）：消息自身的方向强度，1 强利空 → 5 强利好。
- **风险 1–5 星**（绿→红渐变）：波及面，个体(1) → 宏观(3) → 系统性(5)。

两者独立：单只股票暴涨可以是「强利好」但风险星级很低。星形用内联 SVG 而非 ⭐️ emoji，
因为 emoji 颜色固定、无法随等级做渐变。

## 双语实现

- **静态文案**：HTML 元素带 `data-i18n="key"`，由 `applyStatic()` 从 `I18N` 字典填充。
- **数据层文案**：Python 端凡是面向用户的字符串都用 `F.bi(en, zh)` 生成 `{en, zh}` 对象，
  前端用 `L(obj)` 按当前语言取值。涉及 `LEVELS`、`FG_ZONES`、恐慌贪婪分项名与明细、
  `INFLATION_SERIES`、`AUCTION_TENORS`、`TICKER_SYMBOLS` 描述、因子名、各 `*_source` 说明。
- **枚举值不要存文案**：财报的时段与市值档位在 Python 端只存 key（`pre`/`post`/`intra`、
  `vhigh`/`high`/`mid`/`low`），前端再映射成文字 —— 否则切语言时这些字段会残留另一种语言。
- 切换语言调用 `renderAll()` 全量重绘；`t(key, vars)` 支持 `{var}` 占位。
- 校验方式：切到英文后扫描 `.wrap` 内所有叶子节点是否含 CJK 字符。
  预期只剩两处刻意保留的中文 —— 品牌副标题与语言按钮上的「中」。

## 已知局限

- 新闻情绪是**关键词启发式，不是语义分析**，会误判反讽和复杂句式。因此新闻因子只给 20% 权重。逐条的「程度」与「风险星级」同样是启发式排序，不是量化预测。
- 恐慌贪婪指数是**自建 5 分项代理**，不是 CNN 官方值，两者会有十几分差距。
- 事件密集度用平滑饱和曲线 `100·(1−e^(−raw/70))`，不再硬截断；极密期仍会趋近 100，但保留排序。
- Top100 口径是「窗口内有财报的公司中市值最大的 100 家」，不等于全市场市值前 100。
- 财报一致预期用 Futu 口径，与其他数据商可能有差异。
- 新闻源本身也会出错（实测见到把主席 Warsh 写成 Powell、把 Hammack 写成 Harker 的条目）。票委名单等关键事实请以一手来源为准。
- **这是研判框架，不是预测模型，不构成投资建议。**
